# InstaCaption AI — Mood to Caption Studio

A simple, responsive caption generator built with HTML, CSS and JavaScript. It does not need an API key or backend.

## Run the project
1. Extract the ZIP file.
2. Open the `mood_to_caption_studio` folder in VS Code.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.

## Features
- Enter a description of an Instagram post
- Choose Funny, Romantic, Professional, Attitude, Cute or Inspirational mood
- Generate three caption ideas with matching hashtags
- Copy captions
- Save and remove favourite captions (stored in browser localStorage)

## Files
- `index.html` — page structure
- `style.css` — responsive design and styling
- `script.js` — caption generation, copy and favourites
